# 🎮 FreeCodeCamp Relational Databases – Video Game Characters

PostgreSQL database created during the **FreeCodeCamp Relational Databases** workshop.

This database was built interactively in a **GitHub Codespace** using the PostgreSQL `psql` terminal.

## 📦 Contents

- `mario_database.sql` — full database dump with schema and data
- `mario_schema.sql` — schema-only dump

## 🧩 Concepts demonstrated

- 🔗 one-to-one relationships
- 🌿 one-to-many relationships
- 🔄 many-to-many relationships
- 🔑 primary keys
- 🧷 foreign keys
- ✅ unique constraints
- 🧱 composite primary keys
- 🔀 joins
